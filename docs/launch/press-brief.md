# Shadowfetch Linux Press Brief

## What it is

Shadowfetch Linux is a Debian/KDE creative workstation with local AI tooling, signed ISO releases, and a signed APT update path.

## Why it exists

Creative work increasingly depends on rented cloud surfaces. Shadowfetch Linux is a private workstation bet: useful after install, local-AI capable, and honest about what is shipping and what still needs work.

## What is shipping now

- Shadowfetch Linux v1.2.8 “Umbra”
- Debian-testing base with KDE Plasma 6
- Calamares graphical installer
- Umbra visual identity
- Creative app stack
- Local AI setup through Ollama/Open-WebUI
- Signed ISO and signed APT repo
- Public verification, known-issues, hardware, security, roadmap, and FAQ pages

## What is still early

- Secure Boot is not signed yet.
- Debian testing moves faster than Debian stable.
- NVIDIA/hybrid laptops may need tuning.
- Hardware matrix is still being built from tester reports.

## Short pitch

Shadowfetch Linux is young, installable, and unusually explicit about its trust layer. It is worth reviewing not because it claims to replace Debian, but because it has a clear workstation thesis: Debian/KDE, local AI, creative tools, signed releases, and public rough edges.
