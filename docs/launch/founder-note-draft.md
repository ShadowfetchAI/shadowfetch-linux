# Founder Note Draft — Why Shadowfetch Is Building a Linux Workstation Now

Shadowfetch is moving its front door to Linux.

The iPhone and iPad apps are still here. There are 112 public apps in the App Shelf, and that shelf matters because it proves a simple thing: Shadowfetch ships. Small tools, practical jobs, direct usefulness. But the center of gravity has changed.

Shadowfetch Linux is the flagship now.

The reason is not fashion. It is control. Creative work is getting pulled into rented surfaces: rented models, rented storage, rented workflows, rented attention. A private workstation is the opposite bet. It says the machine on your desk should still matter. It should boot into a useful environment. It should have creative tools ready. It should run local AI without making a cloud account the first step. It should be inspectable, updateable, and honest about its rough edges.

Shadowfetch Linux v1.2.8 “Umbra” is built on Debian testing and KDE Plasma 6. It adds the Umbra visual identity, a curated creative stack, Calamares installation, privacy-minded defaults, local AI setup through Ollama/Open-WebUI, signed ISO releases, and a signed APT repository. It does not pretend to be Debian. It does not claim Debian endorsement. It stands on Debian’s shoulders and says exactly what it adds.

That honesty is the product strategy. We publish verification instructions. We publish known issues. We publish hardware notes and a security model because serious users do not need theater. They need specifics.

The App Shelf stays as the field kit: focused mobile tools for daily jobs. The Linux workstation becomes the place where the bigger work happens.

The next phase is straightforward: earn trust, gather real hardware feedback, improve the installer and first-run experience, document what works, document what does not, and cut the next ISO from actual user friction.

Shadowfetch is not trying to be everything. It is trying to be a private, AI-ready creative workstation with enough taste to be coherent and enough humility to show its receipts.
