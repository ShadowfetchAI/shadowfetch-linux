# Shadowfetch Linux Outreach Targets

## Pitch

Shadowfetch Linux is a Debian/KDE creative workstation with local AI tooling, signed ISO releases, a signed APT repo, and public trust pages for verification, hardware notes, security model, known issues, roadmap, and FAQ. It is early, installable, and looking for serious reviewer feedback.
