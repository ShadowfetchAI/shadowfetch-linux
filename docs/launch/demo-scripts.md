# Shadowfetch Linux Demo Scripts

## Demo 1: Boot to desktop

Duration: 30–45 seconds.

1. Show boot menu selecting Shadowfetch USB.
2. Show Umbra boot/login/desktop.
3. Say: “This is Shadowfetch Linux v1.2.8 Umbra, a Debian/KDE creative workstation.”
4. End on desktop with app launcher open.

## Demo 2: Verify before installing

Duration: 45–60 seconds.

1. Open `/linux/verify`.
2. Show SHA-256 and GPG fingerprint.
3. Run verification commands in terminal.
4. Say: “Trust starts before install.”

## Demo 3: Local AI

Duration: 45–60 seconds.

1. Open Welcome/local-AI flow or terminal helper.
2. Show model-size warning/recommendation.
3. Open local chat UI.
4. Say: “The point is local first, not cloud first.”

## Demo 4: Creative tools

Duration: 45–60 seconds.

1. Open Krita, GIMP, Kdenlive, OBS, Blender quickly.
2. Show they are installed, not promised.
3. Say: “This is the weekend setup work already done.”

## Demo 5: App Shelf proof

Duration: 30–45 seconds.

1. Show homepage App Shelf.
2. Show 112 public iPhone/iPad apps framing.
3. Say: “The Shelf proves Shadowfetch ships. The workstation is the front door.”
